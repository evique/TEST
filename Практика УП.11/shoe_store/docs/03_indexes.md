# Проектирование индексов базы данных

| Таблица | Поле | Тип индекса | Обоснование |
| :--- | :--- | :--- | :--- |
| `users` | `role_id` | Обычный | Ускоряет операции JOIN с таблицей ролей[cite: 44] |
| `orders` | `user_id` | Обычный | Ускоряет фильтрацию и соединение заказов по клиентам[cite: 44] |
| `orders` | `order_date` | Обычный | Ускоряет хронологическую сортировку и выборку заказов по периодам[cite: 44] |
| `products` | `category` | Обычный | Ускоряет фильтрацию каталога по категориям[cite: 44] |
| `stock_items` | `product_id`, `size_id` | Обычные | Ускоряет поиск остатков конкретных моделей и размеров[cite: 44] |
| `order_items` | `order_id`, `stock_item_id` | Обычные | Ускоряет формирование чеков и отчетов по составу заказов[cite: 44] |
