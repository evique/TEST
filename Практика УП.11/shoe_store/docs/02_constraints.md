# Ограничения целостности базы данных

* **NOT NULL**: Обеспечивает обязательное заполнение ключевых полей (фамилия, имя, логин, наименование, цена).
* **UNIQUE**: Гарантирует уникальность логинов пользователей (`login`), названий ролей (`role_name`) и значений размеров (`size_value`).
* **CHECK**: Защищает от логических ошибок: цена товара и цена в заказе должны быть строго больше нуля, количество на складе не может быть отрицательным, а количество позиций в заказе — больше нуля.
* **DEFAULT**: Автоматически проставляет текущую дату для новых заказов (`DATE('now')`) и нулевое количество для пустых складов.
* **FOREIGN KEY**: Связывает таблицы между собой и поддерживает ссылочную целостность с помощью правил `ON DELETE RESTRICT` (для защиты от удаления связанных справочников) и `ON DELETE CASCADE` (для автоматической очистки состава при удалении заказа).
