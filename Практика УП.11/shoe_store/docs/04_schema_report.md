## Отчёт о созданной структуре базы данных (Тема 4).

Структура базы данных компании «Чудо Обувь» успешно реализована в файле db/shoe_store.sqlite [cite: 51, 63]. Схема включает 7 взаимосвязанных таблиц (sizes, users, products, stock_items, orders, order_items), первичные (Pk) и внешние (FK) ключи, индексы для оптимизации соединений [cite: 54, 59, 63].
