# Итоговый отчёт за день

В ходе выполнения практической работы успешно проанализирована предметная область компании «Чудо Обувь», выделены ключевые сущности, спроектирована нормализованная до 3НФ структура реляционной базы данных из 7 таблиц. Разработана и экспортирована в PDF ER-диаграмма (`ERD_module_1.pdf`), составлен словарь терминов и проведена проверка покрытия функциональных требований и ролевой модели доступа. Все проектные документы зафиксированы в структуре каталогов репозитория.
