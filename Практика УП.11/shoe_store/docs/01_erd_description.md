# Описание ER-диаграммы

Диаграмма построена в инструменте `draw.io` и включает 7 взаимосвязанных таблиц:
1. roles — справочник ролей пользователей (`role_id` - PK).
2. users — таблица пользователей системы с привязкой к ролям через `role_id` (FK).
3. products — каталог моделей обуви (`product_id` - PK).
4. sizes — справочник доступных размеров (`size_id` - PK).
5. stock_items — складские позиции, связывающие модели (`product_id` - FK) и размеры (`size_id` - FK) с указанием доступного количества.
6. orders — заказы клиентов с привязкой к пользователю (`user_id` - FK).
7. order_items — состав заказов, связывающий заказ (`order_id` - FK) и товарную позицию (`stock_item_id` - FK), с фиксацией цены на момент покупки и количества.
