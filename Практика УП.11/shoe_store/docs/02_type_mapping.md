# Сопоставление типов SQLite и типов демоэкзамена

| Поле из задания | Назначение | Тип SQLite | Тип демоэкзамена | Комментарий |
| :--- | :--- | :--- | :--- | :--- |
| А | Идентификатор пользователя | INTEGER | INTEGER / INT | Совпадает напрямую[cite: 23, 24] |
| Б | Фамилия пользователя | TEXT | VARCHAR / NVARCHAR | Строковое поле произвольной длины[cite: 23, 24] |
| В | Логин пользователя | TEXT | VARCHAR / NVARCHAR | Уникальный строковый идентификатор[cite: 23, 24] |
| Г | Дата заказа | TEXT (ISO 8601) | DATE | Хранится в формате YYYY-MM-DD для корректной сортировки[cite: 19, 23, 24] |
| Д | Наименование товара | TEXT | VARCHAR / NVARCHAR | Строковое поле[cite: 23, 24] |
| Е | Путь к изображению товара | TEXT | VARCHAR / NVARCHAR | Строковый путь к файлу[cite: 23, 24] |
| Ж | Размер обуви | REAL | NUMERIC / DECIMAL | Поддерживает дробные значения (например, 37.5)[cite: 24] |
| З | Доступное количество позиции | INTEGER | INTEGER / INT | Целое число для остатков[cite: 18, 23] |
| И | Цена товара | NUMERIC | NUMERIC / DECIMAL | Точное число с фиксированной точкой для денег[cite: 18, 19, 24] |
| К | Количество товара в заказе | INTEGER | INTEGER / INT | Целое число[cite: 18, 23] |
| Л | Цена товарной позиции в заказе | NUMERIC | NUMERIC / DECIMAL | Историческая цена с фиксированной точностью[cite: 18, 19, 24] |
| М | Идентификатор заказа | INTEGER | INTEGER / INT | Первичный ключ[cite: 18, 23] |
