# Отчёт о финальном DDL-скрипте

Финальный DDL-скрипт (`src/db_init.py` и `db/schema.sql`) спроектирован исполняемым с нуля. Он последовательно создает справочники (`roles`, `sizes`), основные сущности (`users`, `products`), складские остатки (`stock_items`), заказы (`orders`) и табличные связи позиций (`order_items`), после чего создает набор индексов для оптимизации выборок[cite: 38, 46].
