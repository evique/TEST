# Финальная проверка схемы именования (Тема 3)

* Все названия таблиц записаны во множественном числе и в нижнем регистре с использованием `snake_case` (`roles`, `users`, `products`, `sizes`, `stock_items`, `orders`, `order_items`)[cite: 36, 40].
* Имена всех полей указаны в единственном числе (`login`, `price`, `quantity`)[cite: 36].
* Идентификаторы используют стандартный суффикс `_id` (`user_id`, `product_id`, `order_id`)[cite: 36].
* Зарезервированные слова SQL в качестве имён объектов не используются[cite: 36, 40]. Автоматический скрипт `db_naming_check.py` подтвердил корректность схемы.
