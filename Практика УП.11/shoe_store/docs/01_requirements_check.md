# Проверка покрытия функциональных требований

| Требование | Реализующая таблица | Поле / Механизм |
| :--- | :--- | :--- |
| Актуальное количество товарных позиций | `stock_items` | `quantity` |
| Сохранение изображения модели | `products` | `image_path` |
| Выбор обуви моделей и размеров | `stock_items`, `order_items` | Связи по `product_id` и `size_id` |
| Просмотр списка заказов с датой и клиентом | `orders`, `users` | `order_date`, `last_name`, `first_name` |
| Управление заказом (добавление/удаление) | `order_items`, `orders` | Операции CRUD с внешними ключами |
