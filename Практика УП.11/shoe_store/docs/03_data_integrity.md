# Отчёт о проверке ссылочной целостности и стратегий удаления

* **ON DELETE RESTRICT**: Применен для внешних ключей пользователей к ролям, заказов к пользователям, складских позиций к товарам/размерам, а также состава заказа к складским позициям. Защищает исторические и справочные данные от случайного удаления[cite: 37, 43].
* **ON DELETE CASCADE**: Применен для связи состава заказа (`order_items`) с заказом (`orders`). При удалении заказа его зависимые позиции автоматически удаляются из базы, предотвращая «висячие» строки[cite: 37, 43].
* **PRAGMA foreign_keys = ON**: Обязательно активируется при каждом соединении для принудительного контроля целостности связей в SQLite[cite: 43].
